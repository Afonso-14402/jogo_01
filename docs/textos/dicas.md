# Dicas dos ecrãs de carregamento

Aparece uma dica ao acaso em cada carregamento. As dicas só aparecem **depois** de o jogador chegar ao sítio de que falam
(a coluna "Desde" diz quando). De vez em quando, em vez de uma dica aparece uma **frase do diário de Aren** (secção 2).

## 2. Frases do diário de Aren (aparecem às vezes)

Só aparecem depois de o jogador ter encontrado essa página.

- *"A janela azul brilha mais quando estou com medo."*

- *"O frio aqui não é só frio. É esquecimento."*

- *"As estrelas aqui não são estrelas. São janelas."*
- *"A torre lembra-se de tudo o que comeu."*
- *"Olá, Jogador nº 10 000."*
