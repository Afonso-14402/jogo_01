# Progressão: status, classes, skills e equipamento

## 1. Status

| Atributo | O que faz |
|---|---|
| **FOR** (Força) | Dano com armas corpo a corpo, carregar mais |
| **AGI** (Agilidade) | Velocidade de ataque e de movimento, esquiva |
| **DES** (Destreza) | Dano com arco e besta, críticos |
| **INT** (Inteligência) | Dano mágico, MP |
| **VIT** (Vitalidade) | HP, defesa |
| **SOR** (Sorte) | Drops raros, baús melhores, críticos |

- **HP** (vida), **MP** (magia) e **Estamina** (esquiva e ataques fortes).
- **Nível máximo: 100.** A cada nível ganhas **5 pontos** para distribuir.
- Mais ou menos: nível do jogador ≈ andar onde estás.

| Nível 10 | Nível 40 (escolhe 1) | Nível 70 (lendária) |
|---|---|---|
| **Espadachim** | Cavaleiro | Paladino |
| | Mestre de Lâminas | Santo da Espada |
| **Arqueiro** | Atirador | Olho de Falcão |
| | Ranger | Senhor da Floresta |
| **Mago** | Arquimago | Sábio dos Elementos |
| | Necromante | Rei dos Mortos |
| **Tanque** | Guardião | Fortaleza Viva |
| | Berserker | Senhor da Guerra |

Cada classe tem **6 skills** próprias (16 classes × 6 = **96 skills de classe**). Podes usar
qualquer arma, mas as da tua classe dão bónus.

## 6. Equipamento

| Espaço | Notas |
|---|---|
| Arma principal | Aparece no boneco |
| Arma secundária | Troca rápida com um botão |
| Cabeça, Corpo, Mãos, Pés, Capa | Só ícone. **Conjuntos por região** (5 peças) com **bónus de conjunto** |
| Anel ×2, Amuleto | Joalharia |
| Animal de estimação | Segue-te |

### Melhorar e encantar
- **Melhorar** de +1 a +10 no Brom. A partir do +6 pode falhar (mas a arma nunca se parte).
- **Encantar** com **gemas** de elementos: Fogo, Gelo, Raio, Veneno, Luz e Sombra.

**F → E → D → C → B → A → S → SS → SSS**. Sobe com missões da Guilda. Cada rank abre missões
melhores, lojas e partes da cidade. Rank SSS só depois do andar 100.
