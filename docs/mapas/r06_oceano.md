# Mapas — Região 6: Oceano (andares 51–60)

Mapas vistos de cima (o andar 58 é um **corte de lado**). Legenda e regras: [`README.md`](README.md). O que há em cada
andar: `docs/regioes/r06_oceano.md`. No mar: `~~` é **mar fundo** (nada-se; debaixo de água há barra de Ar), `,,` é
**água rasa**, `..` é **areia** (ou chão seco), `**` é **coral** ou **anémonas**, `tt` são **palmeiras** (à superfície)
ou **algas gigantes** (debaixo de água), `==` são cais, palafitas ou o convés, e `JJ` é um barco.
